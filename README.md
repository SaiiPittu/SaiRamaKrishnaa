# Hi, I'm Sai 👋

**Founding Full Stack AI Engineer** at [Synxa IT](https://synxait.in) — building the harness that turns
foundation models into production systems: tool orchestration, sandboxed execution, structured
outputs, and the infra underneath it.

I'm the founding engineer on **Narad**, an AI-native hiring platform — resume screening, AI voice
screening, and a multi-agent technical interview, end to end. I design the architecture, carry it into
implementation with the team, and own deployment and observability across the stack.

- 🔭 Currently building durable, multi-week agent workflows (Temporal) for a candidate pipeline that
  spans days-to-weeks per hire
- 🧠 Deep in harness engineering — agent runtimes, tool-gated state machines, eval harnesses that test
  agent behavior separately from live infrastructure
- 🌱 Also consulting on a SQL Server → PostgreSQL replatform for a Y Combinator-backed client
